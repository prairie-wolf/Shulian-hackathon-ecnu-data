## 共享接口（B/C/D 对接）

所有语义/等价辅助入口接收裸 `rdflib.Graph`。包装对象由调用方传入 `.g`。本次没有修改 C 负责的协议包装兼容逻辑。

- `GenericSemanticQuery(graph).ask(question)` 返回结构化字典。实体论文意图为 `entity_publications`，保留 `entity`、`entities`、`count`、`data`，补充 `uri`、`returned`、`has_more`。`count` 是全部去重论文总量，`data` 最多 30 条，`returned == len(data)`；空关联返回零条，不换成全库。每条含 URI、名称、ID、属性。
- `publications_for(uri)` 返回 `set[URIRef]`。机构论文依据其关联学者的 `authorOf`，不把 OpenAlex `worksCount` 当本平台已收录论文数；多个明确范围取交集。
- `not_found`、`ambiguous`、`unsupported`、`greeting` 的 `hint` 用于解释结果。歧义响应 `data` 含候选 URI、类和国家；调用者可使用确切 URI 重问。
- 学者查询继续返回 `scholars_filtered` / `scholars` / `data`；成员按 URI 区分，返回 `count`、`raw_count`、`returned`、`has_more`。校友/毕业生问句明确说明这里只是平台记录的关联学者，`affiliatedWith` 不证明毕业关系。
- 企业列表 `count` 为等价去重量，`raw_count` 为原始实体量；图谱概览的 `classes()` 仍反映原始类型计数。行业列表只计公司，不混入其他类型。
- `CompanyEquivalence(graph)` 是只读视图。`representative(uri)` 给出稳定代表 URI，`aliases(uri)` 给出原始 URI 集合，`predicate_objects(uri)` 遍历所有别名的去重属性/出边。C 应先按全部别名检索，再按代表 URI 去重、分页，不能只隐藏别名。入边查询也须遍历全部别名目标。
- `link_company_equivalences(graph)` 供 B 在基础数据和公共上传恢复后调用，返回新增 `ONTO.sameAs` 边数。它只追加经过证据核验的链接，不删实体、不复制或覆盖上传内容、不持久化文件。
- 自动企业证据只适用于项目两份已知公共企业快照：类型为 Company，来源与 URI 前缀吻合，名称、地区、营收、员工数同时一致，且两侧候选唯一。其他来源不会因同名被自动合并。现有显式 `ONTO.sameAs` / `OWL.sameAs` 仅在两端都是 Company 时进入视图。
- 查询使用当前图创建视图，没有名称索引缓存；增删、替换和同数量变动均能反映。B 的跨进程刷新仍须先更新/替换实际图对象；刷新后 C/D 不应继续持有旧图。若基础快照变更，B 应从基础数据重建图后重新生成推断链接；显式保存的 sameAs 是图谱中的身份断言，本模块不会自行撤销它。
- 辅助模块不吞掉图操作错误，构建/加载异常继续向调用者抛出。对未知实体和不支持的自然语言范围返回明确响应，不编造答案。
